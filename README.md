# DNS Connect

Android-приложение для диагностики DNS, качества сетевого соединения и доступности интернет-сервисов.

- Package: ru.krenas.dnsanalytics
- Android 8.0+ (API 26)
- Источник проекта и инструкции для новых чатов: HANDOFF.md

## Скачать
- Последний стабильный релиз: https://github.com/Krenas/DNS-Connect/releases/latest
- Все версии: https://github.com/Krenas/DNS-Connect/releases
- Манифест встроенного обновления: https://raw.githubusercontent.com/Krenas/DNS-Connect/main/latest.json

## DNS Connect 2.3.0
Кандидат 2.3.0 прошёл локальную сборку и release-package audit. Включает переработанный главный экран, инструменты в отдельном меню, 20 цветов акцента, независимые DNS-purpose фильтры, управление списком сервисов и потоковую проверку без ограничения общего количества DNS. Перед тем как считать её опубликованной, проверьте релиз 2.3.0 и latest.json.

## Обновления приложения
В настройках доступна ручная проверка обновлений и суточная автопроверка. Приложение проверяет подпись/сертификат, размер и SHA-256 APK, затем открывает системный установщик Android. Для установки нужно подтвердить действие на устройстве.

## Подпись и резервная копия
2.1.0 использовал другой сертификат. Перейти с 2.1.0 на 2.3.0 можно через экспорт резервной копии, удаление 2.1.0, установку 2.3.0 и восстановление. Все дальнейшие релизы должны использовать сохранённый ключ 2.2.x+; JKS/пароль не публиковать.

## Для продолжения
Новый чат может продолжать работу напрямую из публичного GitHub-репозитория, не требуя загрузки файлов от пользователя. Порядок проверки и выпуска описан в HANDOFF.md.
