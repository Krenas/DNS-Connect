# DNS Connect

**DNS Connect** — приложение для проверки DNS-серверов, состояния интернет-подключения и доступности выбранных онлайн-сервисов на Android.

## Скачать

- [Скачать последнюю опубликованную версию APK](https://github.com/Krenas/DNS-Connect/releases/latest)
- [Все версии и список изменений](https://github.com/Krenas/DNS-Connect/releases)
- [История изменений](CHANGELOG.md)

Последняя опубликованная версия отображается на странице Releases. Не устанавливайте APK из непроверенных источников.

## Возможности

- Проверка доступности DNS-серверов и времени ответа.
- Диагностика текущего интернет-подключения.
- Проверка доступности выбранных интернет-сервисов.
- Работа со списком DNS-серверов и группировка записей по назначению.
- Просмотр результатов проверок в отдельных разделах приложения.

Набор функций может отличаться между версиями. Полный список изменений указан в описании каждого выпуска.

## Установка

1. Откройте страницу [последнего выпуска](https://github.com/Krenas/DNS-Connect/releases/latest).
2. Скачайте файл APK для Android.
3. Откройте скачанный файл и подтвердите установку в системном окне Android.

Приложение рассчитано на Android 8.0 и новее.

## Обновления

Проверяйте наличие новых версий на странице [Releases](https://github.com/Krenas/DNS-Connect/releases). В выпусках, где доступно встроенное обновление, оно находится в настройках приложения. Перед установкой новой версии Android покажет системное подтверждение.
