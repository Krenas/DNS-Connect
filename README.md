# DNS Connect

Android-приложение для диагностики DNS, доступности интернет-сервисов и состояния сетевого подключения.

- Package: `ru.krenas.dnsanalytics`
- Минимальная версия Android: 8.0 (API 26)
- Публичная опубликованная версия определяется только по [latest.json](https://raw.githubusercontent.com/Krenas/DNS-Connect/main/latest.json).

## Скачать и обновить

- [Последний опубликованный релиз](https://github.com/Krenas/DNS-Connect/releases/latest)
- [Все релизы и исходные архивы](https://github.com/Krenas/DNS-Connect/releases)
- [Манифест встроенного обновления](https://raw.githubusercontent.com/Krenas/DNS-Connect/main/latest.json)

Встроенный updater проверяет метаданные, размер и SHA-256 APK, затем передаёт APK системному установщику Android. Для завершения установки пользователь подтверждает действие в Android.

## Статус 2.2.0

Подготовлен и локально проверен APK DNS Connect 2.2.0 (versionCode 23). Однако пока он не опубликован в GitHub Releases, а публичный `latest.json` ещё указывает на 2.1.0. До появления релиза 2.2.0 встроенное обновление не предложит эту версию.

Подробный актуальный статус и следующие шаги: [HANDOFF.md](HANDOFF.md).

## Переход с 2.1.0 на 2.2.0

APK 2.1.0 и 2.2.0 подписаны разными ключами. Обычная установка поверх 2.1.0 невозможна. Перед переходом экспортируйте резервную копию, удалите 2.1.0, установите 2.2.0 и восстановите данные. Все следующие версии должны быть подписаны тем же ключом 2.2.x.

## Требования к релизам

Каждый стабильный релиз должен содержать:
- `DNS-Connect-VERSION-release.apk`
- `DNS-Connect-VERSION-source.zip`
- `DNS-Connect-VERSION-SHA256SUMS.txt`

Нельзя публиковать JKS, пароль подписи, приватные ключи или токены в этом публичном репозитории. Для обновлений 2.2.x использовать сохранённый ключ из закрытого хранилища, не генерировать новый.
