# DNS Connect

**DNS Connect 2.1.0** — Android-приложение для диагностики DNS, доступности интернет-сервисов и состояния сетевого подключения.

- Android 8.0+ (API 26)
- Package: `ru.krenas.dnsanalytics`
- versionName: `2.1.0`
- versionCode: `22`
- targetSdk: 35

## Возможности

- Проверка DNS-серверов UDP, DoT и DoH.
- Сравнение задержки и диагностика доступности сервисов.
- Каталог DNS-профилей с фильтрами по назначению.
- Схематичное отображение приблизительной IP-географии.
- История результатов, экспорт и восстановление резервной копии.
- Виджеты DNS, скорости, сервисов и быстрых действий.
- Системная плитка Android для быстрого запуска диагностики.
- Проверка обновлений через публичный GitHub-манифест, с проверкой SHA-256, пакета и сертификата, затем установка через Android.

## Скачать

APK 2.1.0 загружен в публичный релиз [2.1.0](https://github.com/Krenas/DNS-Connect/releases/tag/2.1.0).

Приложение требует тег вида `v2.1.0`. В репозитории уже создан релиз [v2.1.0](https://github.com/Krenas/DNS-Connect/releases/tag/v2.1.0), но в нём пока нет APK. Для безопасного исправления этого несоответствия добавлен workflow:

[**Открыть публикацию обновления 2.1.0 (GitHub Actions)**](https://github.com/Krenas/DNS-Connect/actions/workflows/publish-2.1.0-update.yml)

Нажми **Run workflow** на ветке `main`. Workflow скачает уже загруженный APK из релиза `2.1.0`, проверит SHA-256 и размер, прикрепит его к релизу `v2.1.0`, повторно проверит asset и только потом создаст `latest.json`.

## Как работает обновление

1. Приложение читает `latest.json` из корня ветки `main`.
2. Проверяет версию, тег, путь к APK, SHA-256 и размер.
3. Загружает APK только с разрешённого GitHub Releases URL.
4. Проверяет пакет, версию, минимальный Android API и совпадение сертификата установленной версии.
5. Передаёт файл системному установщику Android. Подтверждение установки обязательно.

## Ограничения и приватность

- Приложение предназначено для диагностики и не меняет системный DNS телефона, не создаёт VPN.
- Сопоставление с OONI выключено по умолчанию и требует явного согласия в настройках.
- Наблюдения OONI не являются официальным реестром РКН.
- IP-геолокация приблизительна и не определяет точное местоположение человека.
- Windows-only операции исходного EXE не эмулируются на Android.
